==================================================
IMAGE PERFORMANCE RULES
==================================================

For major images, generate:
480w
768w
1280w
1920w
2560w only where genuinely useful

Preferred delivery:
1. AVIF
2. WebP fallback
3. PNG only when transparency or exact output requires it

Implementation:
- use srcset
- use sizes
- preload only the actual first hero
- lazy-load below-the-fold images
- specify width/height or aspect ratio
- do not preload both product hero sets on mobile
- keep full-resolution originals outside the public bundle

ANALYTICS RULE

Always track stable asset IDs, never filenames.

GOOD:
asset_id = camel_views_board

BAD:

This prevents analytics history from breaking when files are renamed or reformatted.
